# Dot Auth 🔐

[![pub package](https://img.shields.io/badge/pub-v1.0.0-blue)](https://pub.dev/packages/dot_auth)
[![MIT License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

A powerful and reusable Flutter authentication package with phone number OTP verification using Firebase.

## Features

- ✅ Phone Authentication with OTP
- ✅ Riverpod State Management
- ✅ GoRouter Integration with Auth Guards
- ✅ Responsive Design (ScreenUtil)
- ✅ Customizable Theme
- ✅ Type-safe Models
- ✅ Ready-to-use UI Components

## Installation

```yaml
dependencies:
  dot_auth: ^1.0.0
